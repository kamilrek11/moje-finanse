# Discovery – runda 1: finanse osobiste

Status: w toku. Odpowiedzi właściciela produktu na pytania specjalisty ds. finansów osobistych (identyfikatory zgodne z listą pytań).

## Potwierdzone decyzje
| ID | Decyzja |
|----|---------|
| A1 | MVP: budżet + fundusz awaryjny + cele. Inwestowanie (treści, symulatory) w kolejnym etapie |
| A2 | Kolejność ścieżki sugerowana, wszystkie moduły dostępne |
| B2 | Tylko umowa o pracę w MVP |
| C1 | Domyślna metoda budżetu: 50/30/20, proporcje zmienne |
| C2 | Pełne transakcje (data, kwota, kategoria, notatka) |
| D1 | Miesięczne koszty = suma kategorii niezbędnych z budżetu (wymaga flagi niezbędne/opcjonalne) |
| D2 | Liczbę miesięcy funduszu wybiera użytkownik, aplikacja podpowiada zakres 3–6 mies. |
| E3 | Kalkulator celu: domyślnie prosty podział, opcjonalnie oprocentowanie i inflacja |
| F1 | Produkty w treściach/symulatorach: konto oszczędnościowe i lokata, obligacje skarbowe detaliczne, IKE/IKZE, ETF-y |
| I2 | Symulatory: trzy scenariusze (pesymistyczny, bazowy, optymistyczny), wartości jawnie oznaczone jako przykład, edytowalne |
| J2 | Personalizowane sugestie tylko dla oszczędzania/budżetu, nigdy dla instrumentów |

## Ryzyka do śledzenia
- **J1:** właściciel nie planuje konsultacji prawnej (KNF/MiFID II). Zapisane jako ryzyko. Treści inwestycyjne trzymać na poziomie ogólnej edukacji, bez nazw instytucji i instrumentów, bez rankingów produktów.
